## Frozen contract

Two whole-homolog slots, each an unchanged publicly validated complete haploid
assignment. Each retains native-family endpoint inventory and canonical source-span
unit capacity across all its molecules and orientations. Cross-slot source reuse
is permitted: A/A uses one source twice, not aliases or per-segment resource IDs.
This is a supplied supported-topology restriction, not homology/CNV/ploidy inference.
Only label exchange and public same-source contiguous normalization deduplicate
descriptions. All distinct physical correlated pairs remain in the finite ledger.
Old concatenation rejection records the actual validator error, including topology
mismatch rather than mislabeling it capacity rejection.

Enumerate unordered pairs with replacement from supplied 1/2/4 native assignments.
This finite domain is not candidate discovery or a full route-domain certificate.
Public per-length integer profiles are added with overflow checking before exposure.
Observed sample-positive support is included once; realized zeros pay signal cost;
registry/rule-only zero/zero features retain symbolic zero. With L150, H from the
pooled sample, s=10*sum(H*q)/sum(L*H), R=sum(s-C*ln1p(s/0.1)). Background and C
occur once, not once per homolog. d10 is nominal PER COPY (20 relative to haploid
reference convention), not realized read coverage. No fitted parameters.
Discrete ties use absolute1e-9; independent absolute/background-subtracted formula
checks use 1e-8*(1+abs(score)). No confidence or independent-Poisson claim.

# Observation-compatible physical registry: diagnosis and repair proposal

## Status

**A defect is demonstrated, and a bounded enumeration/count-accounting method
passed independent review. The production repair is not implemented or approved
for a full-panel run.** No new genotype, reconstructed FASTA, QV or whole-genome
coverage result is claimed. The [original sequence controls](whole-genome-sequence-results.md)
remain the frozen comparator.

The accepted production source used by the diagnostics was
`d8a9ce6197cb08b52105c8d35e5317f2cf1e9051`. Panel, dictionary, sketch parameters,
sample collection, sample MEM-BWT, genotype parameters and original candidates

controls—not held-out inference or a source-blind production application.

## Demonstrated mechanism

The catalog enumerates feature locations from adjacent pairs in each **stored
forward source walk**. Its reverse GBWT path reverses that same walk; it is not an
independent sketch of reverse-complement source DNA. Sample collection instead
queries both read input orientations, using the existing higher-anchor selector,
and retains noncontained overlapping MEM records.

Consequently, completeness over stored pairs is not completeness for the sample
observation operator.

## Bounded two-view test

A separately implemented diagnostic was reviewed before the parent compiled and
ran it. It independently calls the orientation-specific native iterator and
frozen dictionary lookup. Calling the public higher-anchor matcher twice would
not expose two independent raw views.

The diagnostic searches **all exact feature-DNA occurrences on every supplied
complete source path**, pairs anchors within each raw view separately, and then
unions physical locations. It never interleaves anchor streams. It also compares
cropped raw views with full-source restrictions and compares coordinate-tagged

## Proposed implementation, in order

### 1. Share the observation primitives without changing the sample

Expose/reuse orientation-specific raw extraction separately from the existing
higher-anchor wrapper. Factor the current coordinate-tagged collection and
content-subwalk pruning so that sample construction still discards coordinates
and emits exactly the same canonical weighted records.

Require unchanged sample payloads/counts on regression inputs, including RC,
ambiguity, repeated features and overlapping MEMs. Coordinates used to compile
expected contributions are transient coordinates of synthetic panel contexts;
no actual-read IDs, placements or read-by-haplotype table are introduced.

### 2. Build a source-blind physical-location sidecar

Keep the existing feature-token universe and IDs initially. For **every panel
source**, extract independent forward and RC raw views with the unchanged
parameters/dictionary. Find existing feature pairs within each view, normalize
to source-forward coordinates, and deduplicate by
`(feature_id, full_source_path, start, end)`.

Retain view provenance without counting views as copies. Preserve distinct
physical spans even when their DNA is identical. Do not insert only the diagnosed
SK1 locations, add dictionary words, concatenate observations, modify source
intervals or silently change the sketch scheme.

Two-view enumeration is a candidate fast path, not an unconditional completeness
theorem. Its sufficient conditions are: cropped raw anchors equal the relevant
full-view restriction; dictionary filtering is identical; and retained MEMs are
contiguous subwalks of the selected read walk. Then an emitted adjacent pair is
adjacent in one of those source views. Expand property/oracle tests to additional
lengths, ambiguity masks, source ends and features with uncovered interiors.
An observed counterexample must fail the capability gate and trigger an exact
context-aware fallback/design revision—not an interleaved-anchor workaround.

Initial capability is **error-free source replay**. Sequencing errors can erase
intervening anchors or change anchor words, so this gate does not establish a
complete prediction model for noisy reads. The capability and limitations must
be explicit in versioned artifacts.

### 3. Recompute complete ownership and context validity

Rejoin every recovered location against all original source occurrences. Rerun
full-span containment, crossing, outside-catalog and shared-group classification.
A location in another group or across a boundary can invalidate a previous
unique owner. Keep exclusions and counts explicit; do not assign by start alone
or expand an interval to retain a useful factor.

The two-path diagnostic cannot certify new global owners. Production ownership
must consume the complete location pass across all relevant sources. BED groups
remain ownership descriptions, not certified homologous loci.

The exposure-support context also matters. Full-source flanks cannot silently be
assumed across a new mosaic junction. The initial local consumer must either
validate the required context or classify the factor as context-dependent and
unresolved/nonlocal, retaining its observation and exclusion reason. This is a
versioned factor-validity change, not frequency masking or a zero-copy call.
Any additional exclusions must be measured against complete genome denominators.

### 4. Compile occurrence-weighted expected contributions

For physical occurrence`o`, let`q(f,o,s,L,theta)` count surviving MEM-substring
contributions at that coordinate from a length-`L` read starting at`s`, under
input orientation`theta`. Preserve values0,1,2,…, including repeated contributions
at one coordinate. Under the declared error-free uniform-start working model:

\[
e_{fo}=\frac{\sum_L n_L\sum_s\mathbb E_\theta[q(f,o,s,L,\theta)]}
                 {\sum_L n_L L},\qquad
\mu_f=\beta+d\sum_o z_o e_{fo}.
\]

Average orientation contributions; do not add them as extra reads. Respect source
ends and valid start bounds. When one read spans multiple copies, assign each
surviving substring to its own synthetic coordinates; never give the read’s total
count to every copy. Sum physical-copy contributions **inside one rate and one
factor loss**.

The old span exposure is recovered when each eligible start contributes exactly
once. A zero-exposure location is not evidence of deletion. Source-context
profiles do not calibrate real coverage, sequencing error, independence between
features, posterior confidence or junction validity.

### 5. Bound memory and prove any execution shortcuts

Do not make another fully materialized41GB JSON object a prerequisite. A proposed
sidecar compiler can stream existing feature definitions into a compact exact
lookup, process one complete source at a time, and externally sort/merge bounded
runs of physical records. Deduplication must be deterministic and retain complete
membership/view provenance. Record input/model fingerprints, completed sources
and checksums for resumable immutable stages; never append to a mismatched run.

The singleton-FASTA oracle is not the production exposure algorithm. First keep
an exact in-memory reference implementation. Only then test reuse of identical
**both-view node/relative-coordinate contexts**, with panel/model/read-length
identity in the cache key, and weighted reuse of consecutive starts proven to
produce identical records. Keep both views and their relative alignment; do not
cache merely by target feature or donor label. Count totals should accumulate as
checked integers before normalization. Cache limits may cause recomputation,
never sampling, truncation or dropped copies.

Profile time, peak memory, scratch space, physical-record counts and exact output
equality before a full-panel run. If source chunking is needed, demonstrate
boundary/crop equivalence with retained halo/ownership rules or use a validated
fallback. No all-panel runtime or memory improvement is established here.

### 6. Integrate as an explicit new model, then evaluate sequence

Use versioned registry/exposure/validity identifiers and reject incompatible
artifacts. Preserve the current scores and old whole-template ranking verbatim;
new locations/exposure/ownership change the objective and require newly labelled
scores. The unchanged sample MEM-BWT may be reused only if its panel and count
policy remain compatible. Reclassification of old scores alone cannot perform
this repair.

Keep depth10, background0.1, existing deviance cutoff and switch penalty fixed in
the first controls. Re-score, rethread and reconstruct afresh. Add the separately
diagnosed background-supported eligibility rule consistently to classification,
threading and reconstruction validation; background preference means unsupported
source evidence, not deletion.

Only after support/ownership are checked should repeated or off-axis bundles gain
new copy-conserving unphased reconstruction. Do not emit one copy per sketch view
or per reference-axis appearance, resolve tied physical multisets arbitrarily,
force the globally identified donor, or impute an unvalidated recombinant join.

## Acceptance gates for that proposal

1. Legacy sample records/counts unchanged by primitive refactoring; old artifacts
   remain explicitly interpretable under their original model.
2. Exact synthetic observation and physical-copy conservation, including zero,
   repeated-MEM and multi-copy contributions; parity with the public oracle.
3. Expanded crop/location tests and an explicit supported capability/error model;
   complete global membership/exclusion accounting on the chosen panel.
4. Bounded, deterministic, restart-compatible resource behavior established before
   authorizing the full-panel compiler.
5. Fresh unchanged S288C/SK1 controls: report errors, conditional alignment QV,
   complete truth/query coverage, unresolved sequence and extra/copy ambiguity.
   Higher conditional QV obtained only by abstention is not complete recovery.
6. Reproduce the complete-template special case under its separately labelled
   objective without restricting ordinary mosaic inference to one donor.

A useful downstream test invariant follows conditionally: for an error-free
in-panel source and a complete observation-compatible registry, any positive
**uniquely owned** feature must have a generating source occurrence in its owner.
A group with no such source bundle cannot retain that source’s positive feature
as exclusive local evidence. Use this to detect incomplete registry/ownership,
not to seed candidates from truth. It does not prove correct sequence placement,
allelic homology or complete reconstructed coverage.

Strict held-outs still require the predeclared whole-identity/alias exclusions and
fresh panel/catalog/sample construction. Recombinant, noisy and coupled-ploidy
gates remain separate and unpassed.

## QUAL emission, delta form: the similarity DELTA (owner ruling, 2026-10-01; supersedes the share form above)

**The share form is MEASURED FALSIFIED.** The forced normalization `share = s_win / Σ s_c` over every distinct class tracked the called set's fraction of the domain's TOTAL similarity mass, not the similarity delta: in these exhaustive domains thousands of eligible near-twin classes each carry substantial similarity, so every measured share lay between 4e-5 and 1e-2 and every finite QUAL between 0.0002 and 0.37 — no discrimination between a confident unique maximum and a genuine tie (the k=2 tie loci scored 0.0006/0.0003, indistinguishable from the separated unique maxima). The section above and its receipts (`cosine-graph-qual-{chrMT,chrI}.jsonl`) remain untouched on disk as the measured falsified record; the receipt checker still reconciles them.

**Derivation of the delta form.** Keep every piece of stage-2 machinery — material-class coalescing (bit-identical node+edge usage signatures merge; class weight = the class's OWN similarity value), called set = distinct classes at the bit-identical maximum, null emission for unbounded/massless loci, the tie-evidence stream — and replace ONLY the quality formula. The called set's confidence over its best alternative is the FORCED TWO-WAY NORMALIZATION `k*s_win` vs `a`: class mass under exclusive hypotheses (either the truth is in the called set or the best alternative wins; classes below `a` are strictly dominated and enter nowhere — any wider normalization would reintroduce the falsified domain-mass dependence). Within a bit-tied called set the truth is UNIFORM — measured in the tie anatomy: every differing node/edge carries zero observed read mass, so this read sample cannot distinguish the tied classes. The emitted call is a single material draw, so the confidence in it is

```
p = (k*s_win / (k*s_win + a)) * (1/k) = s_win / (k*s_win + a)
QUAL = -10*log10(1 - p)
```

with `k` = distinct material classes bit-tied at the maximum `s_win`, and `a` = the best similarity among ALL classes outside the called set (`a = 0` if none). NO free parameters: the Phred convention and the forced two-way normalization are the only derived forms, both documented here.

**Reduction checks.** (i) `k = 1` unique maximum with a clear gap (`a << s_win`) gives `p → 1`, QUAL high; `a = 0` is the unbounded null emission. (ii) An exact k-way tie holding all the domain's similarity (`a = 0`) gives `p = s_win/(k*s_win) = 1/k` and `QUAL = -10*log10(1 - 1/k)` bit-identically (unit-proven for k = 2, 3, 5, 9 in `qual_all_mass_k_way_class_tie_lands_at_derived_bound`, adapted from the share-form test). (iii) A near-twin at `a ≈ s_win` gives `p ≈ 1/2`, QUAL ≈ 3.01 — low and honest. (iv) Coalesced member-level ties never lower QUAL: the formula's only inputs are `(s_win, k, a)`, `k` counts DISTINCT classes only and no member sum exists, so a called class holding 12 route members and one holding 1 produce the same p. Unbounded (`p = 1`, exactly `k = 1` with `a = 0`) and massless (`s_win = 0`) loci emit null plus an explicit flag, never a clamp.

## QUAL emission: derived product semantics on the graph-space ranking path (owner ruling, measured on chrMT/chrI)

**The ruling.** Ambiguity is OK: tied top candidates are a legitimate call. The product emits the CALLED SET plus a PHRED-SCALED QUALITY derived from the similarity delta — derived, not tuned; the Phred convention and the forced share normalization are the only derived forms, no thresholds, no constants, no epsilon. The owner refined the share to MATERIAL-CLASS level: candidates that are the same effective material are not alternatives, and member multiplicity must not inflate confidence.

**Material classes.** The stage-1 condensation already coalesces physical candidate rows into graph rows on EXACT node+edge multiset equality; a candidate material class is an unordered pair of those coalesced rows (the class signature is the pair of row signatures; after coalescing, equal signatures mean the same row, so distinct classes are distinct material by construction). The class weight is the class's OWN similarity value — nine route identities over one material class carry ONE class value, not nine — and the called-set emission carries class signatures (row indices, usage hashes, node/edge counts, member multiplicity), not member route identities.

**Called set.** Per locus, each candidate class has its graph-space cosine s_c on the nodes+edges arm (the stage-1 machinery). The called set is the classes at the bit-identical maximum: exact ties only — identical f64 values; every score is finite, non-NaN, non-negative, and -0.0 cannot arise (non-negative dots over positive norms), so IEEE-754 equality IS bit identity; if two floats differ at bit level they are not ties. No epsilon constant enters the product call. (Receipt note: the observed-norm sums iterate a Rust HashMap, so cosines can vary by a few f64 ULPs across processes — measured at most 4e-16 relative, changing no rank, tie or count; exact-tie detection is therefore receipt-local, and a future production implementation should accumulate deterministically. Not changed in this stage: the scoring machinery is unmodified.)

**Share and QUAL.** share = s_win / (sum of s_c over ALL distinct material classes in the exhaustive domain), summed once per class in the deterministic enumeration order; classes failing the zero-norm guard carry no similarity value and contribute nothing. QUAL = -10*log10(1 - share). share = 1 (the called class holds all the domain's similarity) is UNBOUNDED and emitted as null with an explicit flag — never clamped; a locus with no similarity mass fails closed to null.

**The derived bound (the validation theorem).** For a k-way exact tie at similarity s, the k tied classes alone contribute k*s to the denominator, so share = s/Σ ≤ 1/k and therefore **Q ≤ -10*log10(1 - 1/k)**, with EQUALITY exactly when the tie holds all the domain's similarity mass (every other class scores zero). A clean k-way all-mass tie lands exactly at the bound — shown bit-identically in the source-named unit test for k = 2, 3, 5, 9 (`qual_all_mass_k_way_class_tie_lands_at_derived_bound`) — and the k=1 all-mass case is the unbounded QUAL (the bound -10*log10(0) = +∞). Any competitor mass strictly lowers the share, so measured Q sits strictly below the bound; the receipt checker asserts the inequality fail-closed at every k ≥ 2 locus.

## 1. Replace the local comparison form

The existing local class-pair sweep enumerates diplotypes, but ranks them by the background-relative Poisson/window-mass objective and its in-window omission charge. It is **not** the COSIGT coverage-vector comparison. On the balanced 15×/15× saved sample, its selected exact truth pair is 4/502 where both truth rows exist. The read-only diagnostic `examples/panel_route_spine/cosine_probe.rs` measured two alternative cosines against the *same* truth, selected, eight top unrestricted old-loss pairs and eight top port-viable old-loss pairs (9–18 distinct physical pairs/locus). On the 498 wrong-selected windows, the physical placement-coverage cosine ranks truth first, including ties, **447/498** and at most second **477/498**; the old pooled-window FeatureKey mass under cosine itself yields **422/498** and **461/498**. This supports replacing the **comparison**, while disproving a claim that the pooled vector alone is sufficient to explain all wrong calls. These are restricted ranks, **not an exhaustive genotype accuracy claim**.

Use one fixed, local material coordinate universe for *every* candidate at a locus: panel path and disjoint base-position intervals in the union of its physically spelled candidate intervals. The observed vector `x` projects each saved routed read-MEM record onto its actual physical placements in this universe. Its existing equal routing share is `record multiplicity / number of touched partitions`; deduplicate overlapping subwalk spans **within a record** before adding its share at a base. A multiply placed record can support multiple panel paths according to that same marginal share; this is not a uniquely aligned read. The expected vector of a physical row is depth 15 on every base it spells, zero elsewhere. An unordered diplotype `i,j` expects `e_i+e_j`; score

```
cos(x, e_i+e_j) = (<x,e_i>+<x,e_j>) /
                 (||x|| sqrt(||e_i||²+||e_j||²+2<e_i,e_j>)).
```

No omission-charge term, multiplicity background, pooled Poisson loss, or guessed SK1 truth enters this selection score. Include predicted-only bases in the expected norm: gratuitously covered material **reduces** cosine. Preserve zeros and duplicated-copy dosage; reject/mark a zero-norm observation or candidate rather than silently awarding a score. Keep canonical source intervals, orientations, and distinct physical row IDs even when vectors tie. Compare QV/tie semantics only after measuring exact and near-ties; no ad hoc cosine threshold or probability calibration is assumed. Assessment truth remains inaccessible to inference.

The expensive observed projection and per-row statistics are computed **once per locus**. Each row needs `d_i=<x,e_i>` and `n_i=||e_i||²`; `g_ij=<e_i,e_j>` is the bp-weighted overlap of two source-path interval sets (or a sparse-vector dot product). Then every pair score requires only O(1) arithmetic. Full `R(R+1)/2` unordered pairs cost O(R²) arithmetic, without enumerating features again per pair. Stream scores/rank/ties rather than retaining a dense matrix; share an expected vector only for **exactly identical coverage vectors**. The old Poisson/FeatureKey class equivalence is NOT evidence that two rows have identical physical coverage, so it cannot silently merge their new scores.
